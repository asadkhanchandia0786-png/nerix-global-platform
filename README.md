# Nerix Global Platform

Multi-tenant dashboard, API and call gateway for the Nerix AI receptionist. Start with **START-HERE.md**.

- `npm ci` · `npm run dev` — run locally / on Replit (embedded database for preview)
- `npm run verify` — type-check, run all tests, build
- `npm run gateway:smoke` — simulate one gateway call against a running server
- `npm run backup` / `npm run restore` — database backups (include call data since 0.4.0)

Docs: `docs/WHAT-CHANGED.md`, `docs/CUTOVER-FROM-DENTIVE.md`, `docs/DEPLOY-ORACLE.md`, `docs/ORACLE-GATEWAY-SETUP.md`, `docs/GATEWAY-CONTRACT.md`, `docs/TEST-PLAN.md`.
